# Vespercoil visual overhaul

The Shattered Expeditions now uses an astronomical field-journal direction: deep ink surfaces, ivory type, brass framing, and distinct regional accents. Gameplay systems, saves, and the user-added combat content remain intact.

- New title backdrop and crest; rebuilt title, pause, field guide, observatory, and end screens.
- Rebuilt in-run HUD and level-up draft with icon cards, weapon and passive icons, clearer contract and resource hierarchy, and persistent status-effect chips.
- Distinct floor patterns, landmarks, beacons, caches, altars, hazard areas, and navigation markers in Asterfall Ruins, Ember Foundry, and Hollow Garden.
- New vector silhouettes for the player and all eleven enemy types. Projectiles, pickups, enemy attack warnings, elite rings, and combat effects share the same visual language.
- `preview-title.png`, `preview-expedition.png`, `preview-draft.png`, and `preview-shop.png` show the redesign at 1280×720.

Open `project.godot` in Godot 4.7.2 or later and run the main scene. The existing game logic and data remain unchanged except for drawing/UI code and the projectile scene polygon.
